# R2 설정 스크린샷

`src/ui/screens/r2Setup.ts`의 STEPS[].shot 에 여기 파일명을 지정하면 가이드에 그림이 함께 뜬다.
예: `shot: 'setup/r2/03-bucket-create.png'`

## 규칙
- 파일명: `NN-무엇.png` (단계 번호 순)
- 🔴 **토큰 발급 결과 화면은 절대 넣지 않는다** — Secret이 평문으로 보인다.
- 계정 ID·공개 URL이 찍힌 캡처는 예시값으로 가리거나, 비밀은 아니므로 그대로 두되 판단해 넣는다.
- 넣기 전에 화면에 비밀값이 없는지 **사람이 직접 확인**한다(자동 스캐너는 이미지를 못 본다).
