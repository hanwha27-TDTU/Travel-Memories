# TEST PLAN · Bugeon Journey

설계지시서 §23 + LESSONS §6. **단일 `harness` 문**이 게이트 전부를 돈다 — 정적·생성물 대조·유닛에 더해 **라이브 렌더(실제 브라우저)**까지 같은 명령에 들어 있다. 작업 중엔 좁은 검사, 완료 선언 전 전체 하네스.

> **라이브 층만 전제가 있다**(브라우저 + 최신 `dist`). 전제가 없으면 harness는 **통과가 아니라 「건너뜀」**으로 적고, 마지막 판정문이 "이번 실행은 그 층을 확인하지 않았습니다"라고 말한다. 전제를 갖춰 재려면 `npm run build && npm run live`, CI에서는 `live-render` job이 매 push마다 갖춰서 돌린다. 규율의 상세는 `gates-mechanization-dev` §2-G.

## TPL-1 게이트 설계 규율 (실패모드 방어)

> **축: 게이트가 조용히 거짓 그린을 내는 방식** — 각 항목이 한 가지 실패모드를 막는다.
> **근거: 손목록** — 겪은 사고에서 뽑았다. 파생할 원장이 없다.


- **부분표면 커버리지發 거짓 그린 금지** — "이 게이트가 실제로 무엇을 여는가?" 새 화면/모달은 반응형·a11y 게이트 표면 목록에 추가되지 않으면 미커버(거짓 통과가 아니라 커버리지 0).
- **공허 통과 금지** — 고유 센티넬을 주입해 실제로 나타나는지 단언(매치=≥1, 무매치=0). 깨진 앱이 통과 못 하게.
- **가장 이른 실행 지점 강제** — 검사를 건너뛰는 실패(`[skip ci]` 류)는 CI가 아니라 `commit-msg` 로컬 hook으로.
- **견고한 공유 추출기** — 손수 만든 소스 파서·고정 문자창은 속거나 조용히 깨짐. 균형괄호·빈 캡처 시 명시적 실패.
- **인스턴스가 아니라 결함군을 게이트.**
- **(A)자동 / (B)수동 경계 정직** — AI는 자동층만 "통과". 시각·픽셀·제스처·실기기는 사용자 몫. 재현 불가 수동 잔여위험은 Manual Residual Risk로 문서화(가짜 자동 게이트 금지).
- **미러 테스트 기본 금지** — 운영 순수함수를 직접 테스트. 브라우저 왕복은 데이터/tombstone/read-back/DOM 상태 변화를 단언(버튼 텍스트 아님), 실제 DOM 이벤트 디스패치.

🔴 **이 목록은 계획이 아니라 실재다.** 예전 판은 여섯 디렉터리를 선언했는데 **다섯이 존재하지 않았고**, 그 일들은 다른 자리에서 이미 돌고 있었다(2026-08-09에 세어 보고 고침 · `TPL-9.1`).

## TPL-4 완료의 정의

> **축: 릴리스 한 묶음의 순서** — 앞 단계의 결과가 뒤 단계의 입력이다.
> **근거: 원장 파생** — 정본은 `docs/CONSTITUTION.md`의 「완료의 정의」이고 여기는 요약이다(`TPL-9.3`).

🔴 **정본은 `docs/CONSTITUTION.md`의 「완료의 정의」다.** 여기에 다시 적지 않는다 — 예전 판은 요약해 옮겨 적었고 이미 갈라져 있었다(헌법 §13 「화면을 열어서 보고, 버튼을 눌러 봄」이 여기엔 없었다 · `TPL-9.3`).

순서만 상기용으로: 버전/CHANGELOG 갱신 → 앱 build → 전체 하네스+live(일부 아님) → **화면을 열어 보고 버튼을 눌러 봄(§13)** → Ready PR 그린 → 병합 → 즉시 배포 성공·version.json read-back → 정직한 보고. **이 줄과 헌법이 어긋나면 헌법이 이긴다.**

## TPL-9 이 문서가 못 보는 것

> **축: 원리적 한계와, 트리로 세우자 드러난 어긋남** — 빈 서랍 · 빠진 형제 · 두 곳에 적힌 정의.
> **근거: 손목록** — 사각지대는 정의상 파생할 수 없다.

### TPL-9.1 선언한 검사 계층 6개 중 5개가 **빈 서랍**이었다 — 닫음(2026-08-09)

`TPL-3`은 `tests/unit`·`integration`·`e2e`·`security`·`performance`·`fixtures` 여섯을 선언한다. **실제로 존재하는 것은 `tests/unit` 하나뿐이고(102개 파일), 나머지 다섯 디렉터리는 아예 없다.**

일이 안 되고 있는 게 아니었다 — e2e는 `scripts/verify-*-live.mjs`가, 보안은 `supabase/tests/*.sql`과 `check-migration-grants`가 이미 하고 있었다. **문제는 그 일이 여기 적힌 자리에 없다는 것**이었고, 이 절을 읽은 사람은 있지도 않은 디렉터리를 찾았다.

**닫은 방법**: `TPL-3`을 **실재하는 자리**로 다시 썼고, 자동층에 아예 없는 것(성능·대량·저메모리)은 「없음 — 실기기 몫」이라고 적었다. 그리고 다시 낡지 않게 `check-current-doc-facts`에 축을 붙였다 — 문서가 `tests/<층>`을 선언하면 **그 디렉터리가 실재해야** 통과한다.

### TPL-9.2 필수 시나리오에 **소리(오디오)가 없었다** — 닫음(2026-08-09)

`TPL-2`는 사진·동기화·보안·데이터 보존 넷이다. 그런데 이 앱의 도메인은 여섯이고(`SYNC_DOMAINS`), 백업이 덮는 테이블도 여섯이다 — 그중 **`localAudio`(소리 기록)에 대한 필수 시나리오가 하나도 없다.** 장소·비용도 마찬가지다.

🔴 이건 이 저장소가 이미 아는 결함형이다. 헌법 §7이 기록하듯 **오디오는 태어날 때 형제들의 규율 다섯 곳을 빠뜨렸고**, 그 목록에 「검사 계획」이 하나 더 있었던 셈이다.

**닫은 방법**: `TPL-2.5`(소리)·`TPL-2.6`(장소)·`TPL-2.7`(비용·환율)을 세웠다. 그리고 **다음 도메인이 자동으로 따라오게** `check-current-doc-facts`에 축을 붙였다 — `SYNC_DOMAINS` 6종이 전부 필수 시나리오에 등장해야 하고, 새 도메인이 원장에 생기면 이름 대응을 적지 않는 한 RED다.

### TPL-9.3 「완료의 정의」가 두 곳에 손으로 적혀 있었다 — 닫음(2026-08-09)

`TPL-4`는 헌법의 「완료의 정의」를 **요약해 옮겨 적은 것**이었다. 두 곳에 손으로 적힌 것은 갈라진다(§2) — 실제로 헌법에는 있고 여기엔 없는 항목이 있었다(§13 「화면을 열어서 보고 버튼을 눌러 봄」).

**닫은 방법**: 정본이 헌법임을 명시하고, 남긴 한 줄에 **「어긋나면 헌법이 이긴다」**를 박았다. 상기용 요약은 남기되 권위는 한 곳에만 둔다.

### TPL-9.4 발견과 닫음을 **커밋으로 나눴다**

`TRE-3.2`가 막으려는 것은 **결번의 귀속**이다 — 「원래 없었는지 내가 지운 건지」. 그래서 구조를 세운 판과 닫는 판을 **다른 커밋**으로 뒀다. 앞 커밋의 diff가 「그때 어긋나 있었다」는 증거이고 이 커밋이 「이렇게 닫았다」이다. 귀속은 보존하면서 부채는 남기지 않는다.

### TPL-9.5 여전히 못 보는 것

- **성능·대량·저메모리는 자동층에 없다.** 실기기 몫이고, 그 사실을 `TPL-3`에 적어 둔 것이 이 앱이 할 수 있는 전부다(§10).
- 게이트는 **시나리오가 적혀 있는지**만 본다. 그 시나리오를 **실제로 돌렸는지**는 보지 못한다.
